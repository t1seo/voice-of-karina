# 참조·생성 설정을 함께 재사용하기

2026-09-20, Apple M1 16 GiB에서 MLX Audio 0.5.4와 고정된 Qwen3-TTS 1.7B Base 4-bit로 검증했습니다. [공식 자료 조사](reusable-voice-research.md)와 [이전 품질 개선](quality-improvement-notes.ko.md)을 실제 스킬 기능으로 연결한 기록입니다.

## 실제로 달라진 부분

좋은 참조를 다시 비슷하게 자르던 과정을 없앴습니다. `register`는 파일을 먼저 복사한 다음 WAV 형식·신호·SHA-256·독립 재전사를 검사합니다. `register_candidate`는 분석 결과의 후보와 전사를 그대로 연결합니다. 분석 뒤 파일이 바뀌면 등록하지 않습니다. 원본 채널을 모노로 만든 분석 후보는 원래 샘플레이트를 보존하며, 등록 자체는 바이트를 바꾸지 않습니다.

저장 프로필은 참조 음성·전사와 함께 모델 리비전·언어·실효 샘플링 설정을 보관합니다. MLX 시드는 모델 로드 후 각 문장 직전에 적용합니다. 재사용은 이 설정을 작업에 고정하고, 재시도 시드만 정해진 규칙으로 바꿉니다. 다음 문장을 위해 원본 영상을 다시 내려받을 필요가 없습니다. 설정이 없던 과거 프로필과 이미 소진된 작업의 ID·시도 횟수는 유지됩니다.

새 화자는 같은 사람의 참조 2–3개를 등록하고 같은 문장·시드로 비교할 수 있습니다. 기본은 참조 2개 × 문장 1개 × 시드 2개, 총 4회입니다. 최대 12칸이며 각 칸은 합성 한 번만 허용합니다. 호출 전에 시도 기록을 저장하므로 중단 후 재개해도 횟수가 늘어나지 않습니다. 모든 미리보기 문장이 통과한 참조·시드 조합만 선택 대상으로 제시합니다. 최종 선택은 파일 해시와 연결하고, 저장 후 새 문장은 별도로 검증합니다.

이 기능은 자연스러움을 자동 판정하는 모델이 아닙니다. 파일·발화 내용·끝맺음 위험을 검사하고, 실제 청취 선택을 대화에 남길 수 있도록 한 것입니다. 전사가 통과했다고 특정 인물과 닮았거나 잡음이 전혀 없다고 보고하지 않습니다.

## 카리나 샘플의 정확한 재현

`karina-reviewed-v1` 프리셋은 이전에 좋은 결과를 냈던 48 kHz, 3.051958초 참조를 패키지에 포함합니다. 전사는 “오늘 재밌는 시간 함께 보내봅시다”이고 참조 SHA-256은 `22133aea2c959269cd804edfdd9bcb1b29945d80b9002782aecfcb15f25d898f`입니다. `.omo` 임시 파일이 없어도 설치된 패키지에서 등록할 수 있습니다. 빌드한 wheel 안에서도 같은 해시를 확인했습니다.

새 스킬의 `preset → audition` 경로로 생성한 “확인이 필요해요. 잠깐 봐 주세요.”는 기존 공개 샘플과 **WAV SHA-256이 정확히 같았습니다**:

`462b63a39599394ac9b2b8d945eed34cba9602fe3378846b44b65c856cb9c6e0`

시드 `20260920`, temperature `0.9`, top-p `1.0`, top-k `50`, repetition penalty `1.5`를 사용했습니다. 이는 이번 동일 환경에서 관찰한 재현 결과이며 다른 기기·런타임 버전의 바이트 동일성을 보장하지 않습니다. 끝에 무음·페이드·시간 늘이기를 추가하지 않았습니다.

## 세 음성 자료의 동일 조건 비교

비교 문장은 “확인이 필요해요. 잠깐 봐 주세요.”와 “작업이 끝났어요. 확인해 주세요.”입니다. 각 참조에서 시드 `20260920`과 `20260921`을 사용했고 나머지 설정과 자동 품질 정책은 같게 유지했습니다. 성공한 결과만 골라 집계하지 않았습니다.

| 자료 | 참조 | 자동 검사 통과 / 실제 합성 | 해석 |
| --- | --- | --- | --- |
| 카리나 | 기존 11.346초 | 2 / 4 | 두 attention 결과가 끝맺음 검사에서 보류됨 |
| 카리나 | 검토한 3.051958초 | 4 / 4 | 정확한 공개 샘플 재현 포함 |
| 이채영 | 자동 후보 13.92초 | 4 / 4 | 긴 참조도 유효한 비교 후보였음 |
| 이채영 | 완결 발화 8.993초 | 3 / 4 | 한 done 결과가 끝맺음 검사에서 보류됨 |
| 공개 한국어 읽기 음성 | 원본 9.9초 | 0 / 4 | 자동 검사 실패를 그대로 기록 |
| 공개 한국어 읽기 음성 | 자동 쉼 경계 3.36초 | 1 / 4 | 적격 조합이 없어 비교 음성을 승격하지 않음 |

총 **24회 중 14회**가 현재 자동 검사를 통과했습니다. 실패한 10회는 모두 한국어 모음 끝부분의 급격한 감쇠 검사에 걸렸습니다. 이 수치는 사람이 판정한 발음 오류율이나 자연스러움 점수가 아닙니다. 감쇠 검사는 자연스러운 짧은 끝소리도 보류할 수 있으므로 실제 청취 없이 10개가 모두 잘렸다고 단정하지 않습니다.

이채영 자료는 [맨 노블레스의 단독 MY TYPE 인터뷰](https://www.youtube.com/watch?v=opvsj3J5ccs)입니다. 자동 분석은 147.69–161.61초의 긴 후보를 제시했습니다. 추가로 전체 전사에서 문장이 완결되는 94–103초를 지정해 비교했습니다. 이 두 번째 참조는 완전 자동 선택 결과가 아닙니다. 사람의 신원을 음성 점수로 확인했다고 표현하지 않습니다.

공개 읽기 자료는 [Google FLEURS](https://huggingface.co/datasets/google/fleurs)의 `ko_kr/test` 행 5, 파일 `10115200572671025618.wav`입니다. 같은 파일 안에서 두 참조를 만들었으며, 데이터의 문장 ID를 화자 ID로 취급하지 않았습니다. 해당 자료는 CC BY 4.0으로 공개되어 있습니다. 원본 전체 음원은 이 저장소에 포함하지 않습니다.

이 실험은 “짧을수록 좋다”는 규칙을 뒷받침하지 않습니다. 카리나는 짧은 참조가 유리했지만 이채영은 긴 참조가 두 문장·두 시드 모두 통과했습니다. 또 원본이 깨끗한 읽기 음성이라고 현재 모델에서 항상 좋은 짧은 알림이 나오는 것도 아니었습니다. 적격 결과가 없으면 기준을 낮추거나 새 작업으로 예산을 초기화하지 않고 다른 참조를 요청하도록 했습니다.

## 선택에 쓰지 않은 문장과 재사용

추가 문장은 “잠시 쉬었다가 다음 작업을 시작해 볼까요?”입니다. 카리나는 기존 공개 샘플과 동일한 attention 결과를 근거로 참조·설정을 선택하고 `select_voice → generate(reuse)`를 실제 실행했습니다. 다른 미리보기를 새로 청취했다고 기록하지 않았습니다. 이채영의 청취 선택은 대기하며, 등록된 참조의 설정 복원을 별도로 검사했습니다. 공개 읽기 자료는 실패한 비교 결과를 승인하지 않았습니다.

| 자료 | 참조 | 추가 문장 결과 | 사용한 합성 횟수 |
| --- | --- | --- | --- |
| 카리나 | 검토한 3.051958초 | 두 번째 시도 통과 | 2 / 2 |
| 카리나 | 기존 11.346초 | 첫 번째 시도 통과 | 1 / 2 |
| 이채영 | 완결 발화 8.993초 | 예산 소진, 끝맺음 검사 실패 | 2 / 2 |
| 이채영 | 자동 후보 13.92초 | 두 번째 시도 통과 | 2 / 2 |
| 공개 한국어 읽기 음성 | 자동 쉼 경계 3.36초 | 두 번째 시도 통과 | 2 / 2 |
| 공개 한국어 읽기 음성 | 원본 9.9초 | 예산 소진, 끝맺음 검사 실패 | 2 / 2 |

첫 추가 문장 결과를 본 뒤 세 자료 모두에서 반대편 참조도 검사했습니다. 이 확장은 사전 등록한 실험이 아니므로, 이 작은 표를 일반적인 성능 추정치로 해석하지 않습니다. 기존 실패 작업의 예산은 초기화하지 않았습니다. 비교 24회와 추가 문장 11회, 총 **35회 실제 합성**을 기록했습니다.

[전체 비교 음성·추가 문장 재생 페이지](reusable-voice-evaluation.html)를 로컬에서 열면 실패한 결과까지 재생할 수 있습니다. [기계 판독용 설정·해시·검사 기록](../assets/evaluation/reusable-voices/results.json)은 비교 24개 전체와 추가 문장 작업 6개의 최종 결과를 담습니다. 추가 문장의 앞선 시도 파일과 호출 기록은 로컬 작업 기록에 남아 있으며, 재생 페이지에서는 각 작업의 마지막 파일을 제공합니다.

이채영의 긴 자동 후보가 추가 문장에서도 통과했으므로 수동으로 짧게 자르는 것이 필수 조건은 아니었습니다. 사용자에게는 적격 후보 A·B·C를 재생할 수 있게 제공하고 청취 선택을 대기 상태로 두었습니다.

## 실행 비용과 남은 한계

저장한 참조는 영상 다운로드·분석·후보 비교를 반복하지 않습니다. 다만 새 recipe 경로는 문장별 시도·시드·산출물의 복구를 명확하게 연결하기 위해 **문장마다 TTS 작업을 실행하고 모델을 다시 로드**합니다. 과거 설정 없는 배치 경로의 한 번 로드와는 다릅니다. 따라서 다문장 합성이 빨라졌다고 주장하지 않습니다. 같은 설정의 문장을 묶으면서도 개별 호출 근거를 보존하는 최적화는 남아 있습니다.

끝맺음 검사에 걸린 결과를 무음이나 페이드로 통과시키지 않았습니다. 적격 후보가 없거나 새 문장의 예산이 소진되면 그 실패를 사용자에게 알립니다. 참조 비교, 정확한 설정 재사용, 출력 검증은 반복 가능한 품질 관리 절차이며 모든 영상·화자·문장의 고품질 보장은 아닙니다. 대체 모델은 공식 자료를 비교했지만 이번 실험에서 설치하거나 성능 우위를 검증하지 않았습니다.

## 검증 범위

기존 작업 ID, 레거시 음성 프로필, 시도 횟수, 승인·거절 결과를 보존하는 회귀 검사를 포함했습니다. 중복 요청·중단 전후 복구·동시 호출·파일 변경·다른 참조/문장/시드의 산출물·ASR 장애·선택 재전송을 검사합니다. 실제 사운드 모델 실행과 단위 테스트 결과를 구분하고, 음성 합성 없이 수행한 스킬 문서 테스트를 음질 검증으로 세지 않습니다.

독립 에이전트는 스킬 문서만 읽고 프리셋·새 화자·청취 불가·선택 후 재사용·소진된 재시도·원본 목소리 설계의 여섯 상황을 검토했습니다. 유효 요청 15개와 잘못된 요청 3개의 스키마 검증을 통과했습니다. 별도 QA에서는 실제 스킬 실행·오류 처리 15개, 비교 WAV 24개의 해시·문장·설정, wheel의 정확한 프리셋 리소스를 확인했습니다. 다른 작업 폴더에서 같은 엔진과 저장소를 사용하는 것도 검증했습니다. 자연스러움을 청취로 검증했다는 의미는 아닙니다.

최종 코드 검증은 **테스트 408개**, Ruff 검사·포맷, basedpyright를 통과했습니다. 목표·실행 QA·코드·보안·기존 문맥의 다섯 검토도 통과했습니다. 검토 중 발견한 근거 없는 `passed` 비교 기록은 저장 상태의 구조 검사와 선택 후보 검사 양쪽에서 거부하도록 수정하고 회귀 테스트로 확인했습니다.
